# Odin Recipes

A simple recipe website built with HTML as part of **The Odin Project Foundations** course.

## About the Project

Odin Recipes is a basic multi-page recipe website featuring three recipes:

- Lasagna
- Margherita Pizza
- White Sauce Pasta

Each recipe page includes a description, ingredients, and step-by-step cooking instructions.

The main goal of this project was to practice the fundamentals of HTML and learn how to structure and link multiple pages together.

## Recipes

### 🍝 Lasagna
A classic Italian dish made with layers of pasta, meat sauce, cheese, and baked until golden and delicious.

### 🍕 Margherita Pizza
A simple Italian pizza made with tomato sauce, fresh mozzarella, basil, and olive oil.

### 🍝 White Sauce Pasta
A creamy pasta dish made with a smooth white sauce, Parmesan cheese, garlic, and Italian seasoning.

## Skills Demonstrated

- HTML5
- Creating a basic HTML document structure
- Headings and paragraphs
- Ordered and unordered lists
- Adding images with `<img>`
- Creating links with `<a>`
- Using relative file paths
- Organizing files and directories
- Creating multiple linked webpages
- Basic Git and GitHub workflow
